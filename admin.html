사진 관리

제목을 수정하거나 사진을 삭제한 뒤 ‘변경사항 저장’을 누르면 지도와 타임라인에 함께 반영됩니다. 삭제는 저장 전까지 되돌릴 수 있습니다. 원본 이미지 파일은 보관됩니다. GitHub Pages 반영에는 시간이 걸릴 수 있습니다.

GitHub 저장 연결

GitHub에서 이 저장소만 선택한 Fine-grained personal access token을 만들고, Repository permissions → Contents에 Read and write를 허용해 주세요. 토큰은 이 화면이 열린 동안만 메모리에 보관하며 GitHub API로만 전송합니다.
